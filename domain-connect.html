GUIDED · AVAILABLE AS A SETUP PATH

Manual DNS connection

1
Publish your website to its Netlify site first.
2
In Netlify, add your custom domain and copy the exact DNS records Netlify provides.
3
Open GoDaddy → My Products → your domain → DNS → Manage DNS.
4
Add or update only the records Netlify instructs you to change. Keep existing email (MX) records intact unless you know they should change.
5
Return to Netlify and verify DNS. Wait for propagation and HTTPS certificate provisioning.

Automatic DNS setup

  • Customer-specific authorisation or scoped credentials.

Not connected yet — GoDaddy API authorisation and secure backend setup are still required.

Important before connecting

  • Each generated website needs its own Netlify deployment/site association.
  • DNS records are different for different Netlify configurations. Always use the exact records shown for that site; do not copy generic values from another website.
  • DNS changes can take time to propagate. HTTPS becomes available after Netlify verifies the domain and provisions its certificate.
  • Never share your GoDaddy login, password, one-time code or API secret with support.

This page is an initial connection guide. It does not yet call GoDaddy or Netlify APIs, save domains to an account, or verify DNS automatically.
