01 · Create your account

  1. Open the Amiri Digital Studio website.
  2. Select Sign up or Sign in.
  3. Use your email verification code or Google sign-in when enabled.
  4. Choose whether the website is for you or a client.

02 · Start a project

  1. Open the website builder dashboard.
  2. Select New project.
  3. Enter a clear project name.
  4. Describe the business, audience, goal and pages you need.
  5. Attach useful logos, photos, documents or reference files.

03 · Generate your website with AI

  1. Write what the website should achieve, not just its colours.
  2. List the pages, sections, features and contact methods.
  3. Include exact business details and approved wording.
  4. Generate the first draft and inspect every page.
  5. Correct inaccurate details before publishing.

Prompt example: “Create a mobile-first website for a local beauty shop. Include Home, Products, About, testimonials and Contact. Use the supplied logo and photos. Add a WhatsApp enquiry button. Do not invent prices or product claims.”

04 · Refine and save versions

  1. Preview the website on desktop and mobile widths.
  2. Ask the AI to make one focused change at a time.
  3. Check links, forms, images, spelling and navigation.
  4. Save a new version before major changes.
  5. Keep a copy of the approved final version.

05 · Publish with Netlify

  1. Open the project's Publish or Deploy controls.
  2. Choose the configured Netlify deployment option.
  3. Review the generated site and deployment settings.
  4. Deploy, then test the public Netlify URL.
  5. Publish updates again after approved changes.

This is the intended workflow. Website generation and per-project Netlify deployment still need to be implemented and tested before these controls are available.

06 · Connect a domain you own

  1. Open Domain settings for the published project.
  2. Enter a domain you already own.
  3. Follow the DNS records supplied by Netlify.
  4. Add those records at your domain registrar.
  5. Wait for verification and HTTPS certificate provisioning.

Amiri Digital Studio will support connecting existing domains only; it will not sell domains.

Quick help

What should I include in my AI prompt?

Business type, target customers, website goal, pages, brand style, features, contact details and any supplied reference files.

Can I use a domain I already own?

Yes. The planned workflow connects an existing domain through Netlify after deployment and DNS verification. No domain purchase is required through Amiri.

Should I publish immediately after generation?

No. Review mobile layout, factual details, contact links, forms, privacy notices and spelling first.

Where will the official video lessons appear?

In this Learning Centre. The video area is prepared, but the official screen-recorded lessons must still be created and added.
